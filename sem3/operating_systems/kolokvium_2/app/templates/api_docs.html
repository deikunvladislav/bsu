API Overview

Todo Manager provides a RESTful JSON API for programmatic access to your tasks and user data. All API endpoints are prefixed with /api.

Base URL

https://your-domain.com/api or http://localhost:8000/api for local development

Quick Start

  • Register a user account
  • Login to get your JWT token
  • Include token in Authorization header
  • Start making API requests

Authentication

All API endpoints (except registration and login) require JWT authentication. Include the token in the Authorization header:

// HTTP Header Authorization: Bearer your_jwt_token_here
POST /auth/register
Register a new user account

Request Body

Parameter Type Required Description
username string Required 3-80 characters, letters and numbers only
password string Required Minimum 6 characters

Tasks

Manage your tasks through the API. All task endpoints require authentication.

GET /tasks
Get all tasks for the authenticated user

Query Parameters

Parameter Type Required Description
status string Optional Filter by status (todo, in_progress, done)
limit integer Optional Number of tasks to return (1-100)
offset integer Optional Number of tasks to skip
POST /tasks
Create a new task

Request Body

{ "title": "Complete project documentation", "description": "Write comprehensive docs for the API", "status": "in_progress" }

Response

{ "id": 1, "title": "Complete project documentation", "description": "Write comprehensive docs for the API", "status": "in_progress", "user_id": 1, "created_at": "2024-01-01T10:30:00Z", "updated_at": "2024-01-01T10:30:00Z" }

Code Examples

JavaScript (Fetch API)

// Create a new task async function createTask(title, description, status) { const token = localStorage.getItem('jwt_token'); const response = await fetch('/api/tasks', { method: 'POST', headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' }, body: JSON.stringify({ title, description, status }) }); return await response.json(); } // Get all tasks async function getTasks() { const token = localStorage.getItem('jwt_token'); const response = await fetch('/api/tasks', { headers: { 'Authorization': `Bearer ${token}` } }); return await response.json(); }

Python (Requests)

import requests class TodoManagerAPI: def __init__(self, base_url, token=None): self.base_url = base_url self.token = token self.headers = { 'Content-Type': 'application/json' } if token: self.headers['Authorization'] = f'Bearer {token}' def create_task(self, title, description="", status="todo"): url = f"{self.base_url}/tasks" data = { "title": title, "description": description, "status": status } response = requests.post(url, json=data, headers=self.headers) return response.json() def get_tasks(self, status=None, limit=None): url = f"{self.base_url}/tasks" params = {} if status: params['status'] = status if limit: params['limit'] = limit response = requests.get(url, params=params, headers=self.headers) return response.json()
