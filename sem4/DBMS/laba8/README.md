# Лабораторная работа №8

**Тема:** Построение аналитических отчётов и модификация данных в базе кредитной организации.

## Цель работы
Научиться строить сложные аналитические отчёты с использованием CTE, оконных конструкций, пользовательских функций и `UNION ALL`, а также освоить операции модификации данных (`UPDATE`, `INSERT`) с последующим откатом изменений.

## Задание
1. Построить два аналитических отчёта на заданную дату (`@ReportDate`).
2. Выполнить серию модификаций данных:
   - перенос дат подписания с выходных на рабочие дни;
   - увеличение суммы кредита на 20%;
   - обновление условий шаблонного договора;
   - выдача нового кредита.
3. Выполнить полный откат всех изменений.

## Отчёты

### Отчёт 1. Аналитическая ведомость выполнения обязательств
Для каждого предприятия выводится:
- выдано кредитов;
- оплачено;
- не погашено;
- задолженность.

Реализован через **CTE** (`enterprise_data`, `debt_details`) с `LEFT JOIN`, `ISNULL`, `GROUP BY` и финальным `UNION ALL` для строки «ИТОГО».

### Отчёт 2. Предприятия-должники
Детализация по каждому договору с задолженностью > 0:
- предприятие, № договора, дата, сумма кредита, годовой %, срок;
- «Должно быть получено» (через `dbo.amount_to_return`);
- «Получено банком»;
- «Задолженность банку».

Строка «ИТОГО» добавлена через `UNION ALL` с сортировкой по `sort_priority`.

## Модификации данных

| № | Запрос | Описание |
|---|--------|----------|
| 1 | `UPDATE LA` | Перенос дат подписания с субботы/воскресенья на понедельник |
| 2 | `UPDATE LA` | Увеличение суммы кредита `LA_id = 1009` на 20% (только при отсутствии платежей) |
| 3 | `UPDATE LAT` | Изменение условий шаблона `LAT_id = 104` (срок → 8, ставка → 16%) |
| 4 | `INSERT INTO LA` | Выдача нового кредита №1011 на 750 000 по шаблону 104 |

## Откат изменений
Выполнен полный откат:
- удаление кредита `LA_id = 1011`;
- возврат условий `LAT_id = 104` (9 мес., 14%);
- возврат суммы кредита `LA_id = 1009` → 75 000;
- восстановление исходных дат подписания для `LA_id = 1002` и `LA_id = 1006`.

## Используемые функции
- `dbo.amount_to_return(amount, rate, term)` — расчёт суммы к возврату (из лабораторной работы №7).
