# Лабораторная работа №6

**Тема:** Сложные SQL-запросы, транзакции, представления и индексы в базе данных стоматологической клиники.

## Цель работы
Закрепить навыки написания многотабличных запросов, вычисляемых полей, группировок, а также освоить работу с транзакциями, представлениями (`VIEW`), индексами и копированием таблиц.

## Задание
1. Пересоздать базу данных `little_tooth_clinic` (обновлённая версия без поля `number` в таблице `Teeth`).
2. Написать 13 запросов:
   - многотабличный запрос с `INNER JOIN`;
   - вычисляемые поля (`DATEDIFF`, арифметика);
   - внешнее объединение (`LEFT JOIN`);
   - группировка с `HAVING`;
   - `INSERT`, `DELETE`, `UPDATE`;
   - транзакция с откатом;
   - создание таблицы через `SELECT INTO`;
   - `UNION`;
   - вложенный подзапрос;
   - создание новой таблицы с нуля;
   - создание индекса;
   - создание представления.

## Структура базы данных

| Таблица    | Поля |
|------------|------|
| `Doctors`  | `Doctor_ID` (PK), `Fullname`, `Adress`, `Birthdate`, `Phone` |
| `Patients` | `Patient_ID` (PK), `Fullname`, `Adress`, `Birthdate`, `Preffered_Doctor` (FK → Doctors) |
| `Teeth`    | `Tooth_ID` (PK), `Patient_ID` (FK → Patients), `State` |
| `Visits`   | `Visit_ID` (PK), `Patient_ID` (FK), `Date`, `Doctor_ID` (FK), `Description`, `Paymentform`, `Cost` |

## Что реализовано

1. **Многотабличный запрос** — выборка посещений за 2023 год с именами пациента и врача.
2. **Вычисляемые поля** — возраст пациента и стоимость с НДС (×1.2).
3. **LEFT JOIN** — пациенты и их предпочитаемые врачи.
4. **GROUP BY + HAVING** — пациенты с суммой посещений > 10 000.
5. **INSERT** — добавление нового врача.
6. **DELETE** — удаление врача при отсутствии зависимостей.
7. **Транзакция** — `UPDATE` с последующим `ROLLBACK`.
8. **SELECT INTO** — копия таблицы `Doctors` → `Doctors_Backup`.
9. **UNION** — объединение врачей и пациентов с меткой типа.
10. **Подзапрос** — пациенты с посещениями дороже среднего.
11. **CREATE TABLE** — новая таблица `TreatmentCategories`.
12. **CREATE INDEX** — индекс `IX_Visits_Date` по полю `Date`.
13. **CREATE VIEW** — представление `VisitsDetails` с деталями посещений.
