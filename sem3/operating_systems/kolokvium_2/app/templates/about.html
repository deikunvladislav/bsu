About Todo Manager

Project Overview

Todo Manager is a full-featured task management application built with Flask and modern web technologies.

This project demonstrates REST API design, authentication, database management, and a responsive web interface.

Technology Stack

Backend

  • Flask Web Framework
  • SQLAlchemy ORM
  • JWT Authentication
  • RESTful API Design

Frontend

  • Vanilla JavaScript
  • Responsive CSS
  • AJAX Requests
  • Modern UI/UX

Database

  • SQLite (Development)
  • SQLAlchemy Models
  • Database Migrations
  • Data Validation

Features

  • User registration and authentication
  • Create, read, update, delete tasks
  • Task status management (Todo, In Progress, Done)
  • Responsive web interface
  • REST API for integration
  • JWT-based authentication
  • Database persistence
  • Error handling and validation

Educational Purpose

This project was created as part of an Operating Systems course to demonstrate:

  • REST API design principles
  • Client-server architecture
  • Database management
  • Web application development
  • Authentication and security
