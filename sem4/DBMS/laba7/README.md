# Лабораторная работа №7

**Тема:** Создание пользовательских функций (UDF) в MS SQL Server на примере базы данных кредитования.

## Цель работы
Изучить создание скалярных пользовательских функций, их вложенное использование и применение для расчёта процентов и суммы возврата по кредитным договорам.

## Задание
1. Создать базу данных кредитной организации со таблицами:
   - `client` — клиенты (предприятия);
   - `LAT` — шаблоны кредитных договоров;
   - `LA` — кредитные договоры;
   - `payment` — платежи по договорам.
2. Создать индекс по дате платежа.
3. Написать три скалярные функции:
   - `get_monthly_interest` — ежемесячные проценты;
   - `get_total_interest` — суммарные проценты за срок договора;
   - `amount_to_return` — итоговая сумма к возврату.

## Структура базы данных

| Таблица   | Поля |
|-----------|------|
| `client`  | `client_id` (PK), `client_name` |
| `LAT`     | `LAT_id` (PK), `LAT_term` (1–12), `LAT_annual_rate` (0–50) |
| `LA`      | `LA_id` (PK), `client_id` (FK), `LAT_id` (FK), `LA_annual_rate`, `LA_term`, `LA_amount`, `LA_signement_date` |
| `payment` | `payment_id` (PK), `LA_id` (FK), `payment_date`, `payment_amount` |

## Функции

| Функция | Назначение | Формула |
|---------|------------|---------|
| `get_monthly_interest` | Проценты за месяц | `amount * rate / 1200` |
| `get_total_interest`   | Проценты за весь срок | `monthly_interest * term` |
| `amount_to_return`     | Сумма к возврату | `total_interest + amount` |

## Что реализовано
- Созданы 4 таблицы с ограничениями `CHECK`, `FOREIGN KEY`, `DEFAULT`.
- Создан индекс `ix_payment_date` по полю `payment_date`.
- Заполнены тестовые данные:
  - 6 клиентов;
  - 5 шаблонов договоров;
  - 10 кредитных договоров (с разными состояниями: погашенные, просроченные, без платежей);
  - 20 платежей.
- Созданы 3 скалярные функции с вложенным вызовом (`amount_to_return` использует `get_total_interest`, который использует `get_monthly_interest`).
- Функции оформлены через `DROP FUNCTION IF EXISTS` и `GO` для безопасного пересоздания.

## Файлы
- `tables+data+functions.sql` — создание таблиц, данных, индекса и функций.

## Как запустить
1. Открыть `tables+data+functions.sql` в MS SQL Server Management Studio.
2. Выполнить скрипт (F5) целиком.
3. Проверить работу функций, например:
   ```sql
   SELECT dbo.amount_to_return(500000, 15.00, 6);
   ```
