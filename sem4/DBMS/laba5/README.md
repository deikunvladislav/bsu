# Лабораторная работа №5

**Тема:** Представления, DML-операции, подзапросы и управление индексами в MS SQL Server.

## Цель работы
Изучить создание представлений (`VIEW`), выполнение операций вставки, обновления и удаления данных, использование подзапросов, `UNION`, `SELECT INTO`, а также управление индексами.

## Задание
1. Создать представление `order_details`.
2. Написать аналитические запросы с `JOIN`, `LEFT JOIN`, `GROUP BY`, `HAVING`.
3. Выполнить DML-операции: `INSERT`, `UPDATE`, `DELETE`.
4. Создать новую таблицу на основе выборки (`SELECT INTO`).
5. Использовать `UNION` и подзапросы.
6. Создать таблицу `order_summary` и индекс `IX_users_phone`.

## Что реализовано
- Создано представление `order_details`, объединяющее данные из 4 таблиц.
- Написаны запросы:
  - выборка доставленных заказов с суммой > 50;
  - расчёт стоимости продаж;
  - `LEFT JOIN` для пользователей и заказов, товаров и продаж;
  - агрегация по категориям с фильтрацией `HAVING`;
- Выполнены операции:
  - `INSERT` в `users` и `orders`;
  - `DELETE` из `orders` и `users`;
  - `UPDATE` статуса заказа;
- Создана таблица `high_value_orders` через `SELECT INTO`.
- Использован `UNION` для объединения пользователей и поставщиков.
- Написан подзапрос для поиска пользователей с суммой заказов выше средней.
- Создана таблица `order_summary`.
- Удалён и создан заново индекс `IX_users_phone` на поле `phone_number`.
